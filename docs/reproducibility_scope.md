# Reproducibility scope

The anonymous package reproduces deterministic graph and operator behavior on synthetic facts. The main paper's FinQA, TAT-QA and annual-report aggregates were generated in a separate controlled workspace. Item-level outputs, prompt caches, sealed identifiers and model checkpoints are not included. The numerical replay report distinguishes the older serializer (83/91) from the revised answer-conditioned serializer (91/91); the package does not claim to reconstruct complete sealed traces.
